# 乖离率超跌反弹策略工具

> 一套基于 **BNF 乖离率战法**（日本交易员小手川隆 / BNF 的超跌反弹思路）的 A 股本地量化工具：
> 全市场扫描 → 计算「信号广度」→ 只在市场极度恐慌时出手。

**⚠️ 重要声明：本项目仅用于数据研究与技术学习，所有内容均不构成任何投资建议。**
**股市有风险，任何策略都可能亏损，请自行决策并控制仓位。**

---

## 一、核心思路

用**乖离率（BIAS）**衡量股价偏离均线的程度：跌得越狠，反弹概率越高。但"跌得狠"的股票天天都有，
真正决定胜率的是**市场整体恐慌程度**。

本项目的关键变量是 **「信号广度」**：

> 当日全市场同时满足以下条件的股票数量

| 条件 | 阈值 |
|---|---|
| 乖离率 BIAS(24) | ≤ **-15%** |
| 成交量 | ≥ 5 日均量 × **1.5** |
| 近 5 日涨跌幅 | < **0** |
| 成交额 | ≥ **8000 万元** |
| 上市交易日 | ≥ **60 日** |
| 其他 | 非 ST / 非退市 / 非北交所 |

**广度越大 = 市场越恐慌 = 超跌反弹的统计胜率越高。** 广度低于门槛时，正确操作是**空仓等待**。

---

## 二、关键结论（六年全市场回测：2021-01 ~ 2026-08）

| 指标 | 数值 |
|---|---|
| 出手门槛 | 信号广度 ≥ **50** |
| 胜率 | **85.6%** |
| 平均单笔收益 | **+4.37%** |
| 盈亏比 | 4.81 |
| 出手频率 | 六年 **22 天** ≈ 每年 3~4 次 |

### ★ 诚实边界（请务必阅读）

1. **收益大头来自极端崩盘月**。2025-04 / 2024-02 / 2022-04 三个月贡献了 44.4% 的信号。
   **剔除这三个事件月后，胜率仍有 61.5%，但平均收益只有 +0.33%。**
   → 请用 **+0.33%** 作为日常预期，不要用 +4.37%。
2. **机会极稀疏**。广度 ≥ 50 六年只有 22 天。大多数日子「今天不动手」是**正常状态，不是故障**。
3. **胜率与当年崩盘级别强相关**：2025 → 98.8%；2024 → 78.2%；2022 → 89.3%；2026 至今（无极端崩盘）→ 62.8%。
   → 对外说明应给区间「60%~90%」，不应只报 85.6%。
4. **广度择时提供独立 alpha，但不能脱离崩盘事件理解**：不设门槛时六年平均为 **-0.21%**（负收益），
   设门槛后转正 —— 这正说明门槛的价值。

## 三、交易规则

| 环节 | 规则 |
|---|---|
| **入场** | 广度达标日的**次一交易日**开盘买入；最多 10 只，资金平均分配，分 2~3 批 |
| **止损** | 收盘价 < 买入价 × **0.94**（-6%）→ **次日开盘卖出** |
| **止盈** | +6% 卖出一半；+10% 全部清仓 |
| **移动止盈** | 浮盈曾达 +5% 后，从最高点回撤 **3%** → 清仓 |
| **时间止损** | 持有满 **10 个交易日**仍未触发以上条件 → 到期卖出 |

> 止损用**收盘价**判定，不是盘中价 —— 回测显示：盘中 -3% 止损会被"插针"误伤（止损率 54.6%），
> 改用收盘 -6% 后降至 21.8%。

## 四、本地工具站（`webapp/`）

一个零成本、纯本机运行的可视化工具：网页看板 + 任务引擎 + 桌面控制台。

```
webapp/
├── strategy_core.py     核心引擎：股票清单 / 数据抓取 / 指标计算 / 广度与候选股
├── updater.py           数据更新器：拉全市场日线 → 算广度 → 入库
├── tasks.py             任务引擎：盘前 / 盘中 / 盘后 三个任务 + 持仓体检
├── server.py            Flask 后端（含用户可控调度器）
├── db.py                SQLite（广度 / 候选股 / 持仓 / 任务设置 / 执行历史）
├── control.py           桌面控制台：启停网站、跑任务、创建快捷方式
├── 控制台.bat           控制台入口（纯 ASCII，规避中文路径编码问题）
├── app.ico              图标（脚本现场生成，无需 Pillow）
└── webui/index.html     单页看板（手写 Canvas 图表，无外网依赖，断网可用）
```

### 三个基础任务（全部由用户决定是否执行）

| 任务 | 建议时间 | 耗时 | 作用 |
|---|---|---|---|
| 🌅 **盘前** | 09:10 | 几秒 | 输出今日操作清单：卖什么 / 买什么 / 还是不动 |
| ⏱ **盘中** | 14:30 | ~1 秒 | 持仓实时预警（+6% / +10% / -6% / 回撤 3%） |
| 🌙 **盘后** | 17:30 | 15~25 分钟 | 更新全市场数据 → 算今日广度 → 明日操作计划 |

**设计原则：「执行权归用户」。** 三个任务默认**全部关闭**，只有用户在网页上显式打开定时开关后才会自动触发；
关掉开关就永远不会自动跑。电脑关机 / 网站没开时定时器不工作（**故意如此**，避免不知情时被自动执行）。

## 五、怎么跑起来

### 5.1 Windows 零基础版（推荐，任何人拿到都能用）

**只需 4 步，不需要懂编程。**

| 步骤 | 做什么 | 说明 |
|---|---|---|
| **1** | 装 Python | 到 https://www.python.org/downloads/ 下载安装，**安装时务必勾选最下面的 `Add Python to PATH`** |
| **2** | 下载本项目 | 点本页右上角绿色 `Code` → `Download ZIP`，解压到任意目录（例如 `D:\股票工具`）。或者 `git clone` |
| **3** | 双击 `webapp\控制台.bat` | **首次会自动联网安装依赖，约 1~3 分钟**，请耐心等窗口跑完 |
| **4** | 首次先跑一次「盘后任务」 | 控制台菜单里选盘后任务，它会下载全市场日线（**约 15~25 分钟**）。下完就有数据了 |

之后每次使用：双击 `webapp\控制台.bat` → 选「启动工具网站」→ 浏览器会自动打开 `http://127.0.0.1:8000`。

> 控制台脚本会自动寻找你电脑上的 Python（支持系统 PATH、虚拟环境、`py -3` 启动器等多种情况），
> 你**不需要改任何路径、也不需要配置环境变量**。

### 5.2 命令行版（给熟悉命令行的用户）

```bash
# 1. 安装依赖
python -m pip install -r requirements.txt

# 2. 首次运行：拉取全市场日线（约 15~25 分钟）
python webapp/updater.py

# 3. 启动工具站，浏览器打开 http://127.0.0.1:8000
python webapp/server.py
```

### 5.3 关于数据（重要）

- **行情数据不随仓库分发**（合计约 2.2GB，GitHub 放不下也不合适放）。
  首次运行会从**新浪财经免费接口**自动拉取并缓存到 `data_long/`，之后每日增量更新。
- **唯一随仓库分发的数据文件**是 `data_long/_universe.csv`（100KB）—— 这是**回测口径的股票清单（5017 只）**。
  它必须随仓库走，否则程序会退到交易所口径清单（4414 只），算出来的「信号广度」与本项目回测结论对不上，
  **门槛 50 的语义会漂移**。请不要删除它。
- 数据源全部免费公开、无需注册、无需 API Key：日线用**新浪财经**，盘中实时价用**腾讯**快照。

### 5.4 环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows（开发与验证环境）。代码本身是跨平台的，macOS / Linux 需自行写启动脚本 |
| Python | **3.9 或更高**（验证环境：Windows + Python 3.13） |
| 依赖 | 见 `requirements.txt`；`akshare` 会自动带入 `mini-racer`，无需手动装 |

| 端口 | `8000`（被占用时会提示） |

## 七、已知限制（诚实边界）

1. **幸存者偏差**：本机清单为「当前仍在市」的股票，回测样本含已退市股。
   本机口径少 2 个达标日，方向更保守（实盘买不到已退市股）。
2. **数据源是免费的公开接口**（新浪财经 / 腾讯行情），没有任何 SLA：
   若对方改版、限流或封 IP，可能抓不到数据，需要更换数据源。
   首次全量下载约 5000 次请求，**如果被判限流，等几分钟重跑即可**（已下载的不会重复下）。
3. **依赖 akshare 版本**：本项目在 akshare 1.18.94 上验证。akshare 更新频繁，
   接口函数签名可能变化；若报错请先尝试 `pip install -U akshare`，或用 `requirements.txt` 约束。
4. **广度口径依赖 `data_long/_universe.csv`**：删掉它就会退到 4414 只的交易所口径清单，
   广度数值会与本项目回测结论产生偏差。**请勿删除该文件。**
5. **不含停牌防护**：回测中的停牌防护用到了未来信息，实盘不可知，已按诚实原则剔除。
6. **涨跌停无法买入**的情况无法完全模拟（如达标日次日一字涨停）。
7. **定时器不抗关机**：进程内调度，网站未运行时不触发（设计如此）。
8. **磁盘占用**：全市场日线缓存约 2~3 GB；汇总计算时内存峰值 2~3 GB。
9. **平台**：启动脚本（`.bat`）仅面向 Windows。Python 代码本身跨平台，
   但需要自行提供 macOS / Linux 的启动方式。
