### 崩溃原因（已定位）
`akshare/stock/stock_zh_a_sina.py` 中 `stock_zh_a_daily`（第 127 行起）**每次调用都新建 `py_mini_racer.MiniRacer()`**（第 178 行）。8 线程并发创建 V8 上下文时触发原生崩溃：

```
FATAL:partition_address_space.cc(243)] Check failed: !IsConfigurablePoolInitialized()
```

（2 年那次侥幸没崩，属竞态；长周期这次在第 1 批就崩了。）

### 修复方案（推荐 A）
在 `fetch_one` 之前加一段 monkey-patch，**串行化 MiniRacer 构造**：

```python
import threading, py_mini_racer
_init_lock = threading.Lock()
_orig_init = py_mini_racer.MiniRacer.__init__
def _patched_init(self, *a, **kw):
    with _init_lock:
        _orig_init(self, *a, **kw)
py_mini_racer.MiniRacer.__init__ = _patched_init
```

- 方案 B（兜底）：`WORKERS=1` 串行下载（约 90 分钟，太慢，不推荐）
- 方案 C（兜底）：主线程先 warm-up 一次 `stock_zh_a_daily`，再启动线程池

## 四、方法学注意事项（写报告必须声明）

- **生存者偏差**：标的池用「当前仍上市且当前非 ST」的股票，剔除当前 ST 会移除已恶化的公司，高估收益。
- **前视偏差**：信号用 T 日收盘数据、T+1 开盘买入，无前视；已修正 T+1 违规（原代码建仓当日即可卖出）。
- **异常值**：300862 蓝盾光电持有期内停牌后连续一字板，单只贡献 4 笔 +196%~+269%；已加停牌防护（相邻交易日间隔 >12 自然日则剔除）。
- **成交假设**：分层止盈按限价单在目标价成交；止损盘中触及按止损价、跳空按开盘价；成本单笔往返 0.4%。
- **未应用 PE 剔除亏损股**：东财接口被代理拦截，无历史 PE 数据源；该条件仅实盘工具可用。
- **未见顶/跌停不可卖**的流动性约束（收盘价止损在跌停时实际无法成交）。
